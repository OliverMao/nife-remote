## 被控端和控制端同时在跑

双击运行（Windows 要先安装，见 [Windows 安装版](#windows-安装版)）就会打开控制台窗口，**首页顶部是本机的连接码和配对码**：别人用这个码连本机，你也能在同一个窗口里连别人，两边互不影响。配对码旁边有**修改**，可以自己填一个（6 位数字，马上生效）。关掉窗口只断你自己的会话，本机还是能被别人连；从托盘菜单能再把窗口打开。

右下角是托盘图标：灰色表示没连上服务器，彩色表示已连接。右键菜单里有：

- 本机控制码（也可以选“复制控制码”）、服务器状态
- **配对码**、“复制配对码”和**更换配对码**：没配对过的控制端第一次连接本机时，除了控制码还要输入配对码（见下面的“配对”）
- 正在控制本机的控制端（连接后面是**安全码**），以及**断开所有控制端**
- **更换控制码**：旧码立即失效，已连接的控制端会被断开；配对码也换一个，配对过的控制端全部忘掉
- **忘掉已配对的控制端**：它们下次连接要重新输入配对码
- **打开控制台**、**开机自动启动** / 语言 / 退出

掉线后会按指数退避自动重连，并且**取回原来的控制码**（服务器重启后也能取回）。控制码是**固定的**：保存在 `config.toml` 里，服务器为这台电脑一直保留它，离线多久都不会分给别人（180 天没有上线才释放），所以重启、升级之后都不变，直到你主动更换。

**配对**：控制码是中转服务器分配的，服务器知道所有控制码，所以只凭控制码不能连上本机（否则服务器自己就能连上来）。一台控制端第一次连接本机时，要输入托盘菜单（或者控制台首页）里的 6 位**配对码**；配对码不经过服务器。配对之后本机记住这台控制端，以后只要控制码。有人连续输错 5 次配对码时配对会暂停，托盘里会提示，换一个配对码就恢复。不想要配对码（例如只在自己信任的服务器上用）时，在 `config.toml` 里写 `access = "open"`。详见[安全 → 端到端加密](security.zh-CN.md#端到端加密)。

## Windows 安装版

Windows 上用安装程序安装（装到 `C:\Program Files\Nife Remote`，所有用户共用，需要管理员权限）。被控端作为系统服务 **Nife Remote** 运行：以 SYSTEM 身份运行在当前坐在屏幕前的用户的会话里，所以锁屏、登录界面和 UAC 确认框上也能照常控制，切换用户时也会跟过去。托盘图标是一个普通程序，显示服务的状态、操作服务：

- 打开 Nife Remote 时启动服务；托盘里**退出**时停止服务（和以前一样，退出后本机不能再被控制）；服务停止（或者被卸载）时托盘也随之退出
- **开机自动启动**（托盘菜单，默认开启）：开机时启动服务，登录之前就能被控制；登录后出现托盘图标
- 配置文件 `config.toml` 在安装目录里（安装时生成，见[配置文件](#配置文件)），由服务维护；要用管理员身份修改
- **卸载**（设置 → 应用）会停止并删除服务、开机启动项、`config.toml` 和程序，不留下任何东西（见[卸载](#卸载)）。在旧版本上安装新版本时保留 `config.toml`（也就保留了控制码和我的设备），选择“先卸载旧版本”也一样
- 没有安装的 `nife-remote.exe` 不能直接运行：发布版会提示运行安装程序。调试构建（`npm run tauri dev`）在托盘进程里运行被控端，`config.toml` 放在程序旁边（`client/src-tauri/target/debug/`）

## 配置文件

Nife Remote 要保存的东西都在一个 `config.toml` 里（里面有注释）。控制台的设置里也能看到它的位置：

| 位置 | 说明 |
|---|---|
| `C:\Program Files\Nife Remote\config.toml` | 安装目录（没有安装的调试构建在程序旁边） |

| 键 | 说明 |
|---|---|
| `server` | 中转服务器 `host:port`；不设置时使用编译进程序的地址 |
| `server_fp` | 中转服务器的证书指纹；`""` 表示不固定指纹：第一次连接时记住服务器的证书（`[server_trust]`），之后证书变了就拒绝连接；不设置时使用编译进程序的指纹 |
| `[server_trust]` | 由 Nife Remote 写入：没有设置指纹时，第一次连上中转服务器时记下的证书指纹。服务器确实换了证书时删掉这一段 |
| `access` | 没配对过的控制端能不能连本机：`"pairing"`（默认）要输入托盘里的配对码；`"open"` 知道控制码就能连（等于信任中转服务器） |
| `autostart` | 开机自动启动（托盘菜单里也可以切换） |
| `[code]` | 本机的控制码，以及取回它用的密钥。删掉 `code` 和 `secret` 就会重新分配 |
| `[host]` | 由 Nife Remote 维护：本机作为被控端的端到端加密身份（`key`）、配对码和它有没有暂停，都是加密保存的。删掉 `key` 会生成新的身份：连过本机的控制端会提示本机的身份变了 |
| `[[paired]]` | 由 Nife Remote 维护：配对过的控制端（公钥、名称、配对的时间），不用配对码就能连。删掉一项就是忘掉那个控制端 |
| `[controller]` | 由 Nife Remote 维护：控制台的端到端加密身份（加密保存，Windows 上每个账户一把）。配对过的电脑靠它认出这个控制台，删掉了就要重新配对 |
| `[[device]]` | 控制台的**我的设备**：连接过的电脑（控制码、对方的名字、自己起的名字、上次的画质、最后连接的时间、对方的公钥 `host_key`），连上时自动保存，最多 50 台。手动添加时 `code` 写 6 位数字就行 |

- 改了设置要重新启动 Nife Remote 才生效（退出，再打开）。Nife Remote 保存控制码和设备时会保留你改过的内容和注释
- **不小心删掉了**（这个文件或者整个目录）：启动时、以及运行中几秒之内，按默认配置重新生成；本机的控制码、开机自动启动、端到端加密的身份、配对过的控制端和我的设备从删掉之前的内容接着用，不会丢，其余设置回到默认
- 控制码能直接控制对应的电脑，相当于钥匙。文件在安装目录里，本机的所有账户都能读：本机的密钥用 SYSTEM 账户的 DPAPI 加密，我的设备里的控制码用保存它的那个 Windows 账户加密，别的账户、别的电脑都解不开（同一台电脑上每个账户只看得到自己的设备）
- 卸载时删除，见[卸载](#卸载)

## 卸载

按下面的步骤做完，Nife Remote 在这台电脑上不会留下什么。配置文件里有本机的控制码和“我的设备”里别的电脑的控制码（相当于钥匙），不再用 Nife Remote 的话请一定删掉。

### Windows

设置 → 应用 → Nife Remote → 卸载。卸载程序会停止并删除系统服务 Nife Remote、开机启动项，删除安装目录（包括 `config.toml`）、安装程序写的注册表项、Windows 防火墙里为 `nife-remote.exe` 添加的规则，以及控制台的临时目录。不用再手动做什么。

（升级时选择“先卸载旧版本”不算卸载：会保留 `config.toml`，见 [Windows 安装版](#windows-安装版)。）

## 控制端

控制台窗口就是控制端。启动时就会打开；**点关闭只是把界面收起来**（不弹确认，控制端、被控端都照常在跑，正在进行的远控也不会断），从托盘菜单的**打开控制台**可以再打开。要真正退出程序，用托盘图标的右键菜单里的**退出**。

- 界面和浏览器一样：每台电脑一个**标签**，可以拖动排序，中键或 × 关闭（= 断开）。点 **+** 新建连接，输入 6 位控制码（可以直接粘贴 `123 456`），连上后这个标签就变成那台电脑。连着两台以上时最左边有**多屏总览**标签
- **第一次连接一台电脑**：对方（桌面版默认）要求配对码时，新建连接页上多出一栏“配对码”，输入对方托盘菜单里的 6 位配对码再连（也可以一次粘贴 12 位：控制码 + 配对码）。配对之后对方记住本机，以后不用再输
- **端到端加密**：会话是端到端加密的，中转服务器看不到画面和键盘输入。第一次连上一台电脑时记下它的身份；之后它的身份变了（重装过，或者有人冒充它），控制台会提示、不会自动重连，确认是对方重装了之后，输入对方托盘里现在的配对码重新配对。鼠标停在工具栏的控制码上能看到**安全码**，和对方托盘里显示的一样就说明中间没有人
- **我的设备**：连接过的电脑自动保存（在 `config.toml` 里），下次在新建连接页点一下就连，用上次的画质；可以重命名、移除（能撤销），设备多了可以搜索。对方不在线时不报错：打开标签等它上线，一上线就连上（带着上次的重连凭证，不算猜码）
- 窗口没有系统标题栏：拖动标签栏的空白处移动窗口，双击最大化。标签栏右侧的齿轮是设置：本机名称、语言、配置文件、快捷键说明。关闭窗口（包括任务栏、Alt+F4）只是收起界面，不会退出程序
- 快捷键（不在操作远程电脑时）：Ctrl+T 新建连接、Ctrl+W 关闭标签、Ctrl+Tab / Ctrl+Shift+Tab 切换标签、Ctrl+1~9、Ctrl+Shift+T 重新打开刚关闭的连接。远程画面有焦点时按键都发给对方
- 工具栏（像地址栏）：对方名称、控制码、帧率 / 码率 / 延迟、编码器；显示器切换、**画质**、快捷键、剪贴板（双向同步 / 以键盘输入方式发送）、声音（静音 / 音画同步）、麦克风（对方能接时才有，见下面的[麦克风](#麦克风)）、1:1 原始大小、全屏、断开
- 全屏时标签栏隐藏，鼠标移到屏幕顶端出现工具栏，点对方名称可以切换到其它连接（仍然全屏）。全屏时会尝试锁定键盘，Win 键、Alt+Tab 这类系统快捷键也发给远端
- **游戏里转视角**：对方的光标隐藏时（例如魔兽世界里按住右键转视角、第一人称游戏），鼠标自动改发相对移动，本机指针锁定在画面上，拖多远都不会碰到屏幕边停下；对方的光标重新出现时自动解除（按着鼠标键时等松开再解除：有的游戏转视角时光标会一闪一闪），也可以按 **Ctrl+Alt+Shift+M** 或长按 Esc（约 1 秒）解除（全屏时键盘被锁定，短按的 Esc 照常发给对方）。游戏没有隐藏光标时，用工具栏的鼠标按钮或 **Ctrl+Alt+Shift+M** 手动锁定，同样用 Ctrl+Alt+Shift+M 或长按 Esc 解除
- 网络抖动导致的断开会自动重连；被控端的用户断开了你时，控制台会说明原因，不再重连
- 对方电脑离线了（关机、睡眠、断网）：控制台显示“等待对方重新上线”，对方一上线（取回原来的控制码）就自动连上。等待期间不会反复尝试，也不会被服务器当成猜码而限速

**画质面板**：预设从省流（720p / 24 fps / 1.2 Mbps）、均衡（1080p / 30 fps / 4 Mbps）、流畅（1080p / 60 fps / 8 Mbps）、高清（1440p / 60 fps / 16 Mbps）到原画（原始分辨率 / 60 fps / 30 Mbps），也可以自己调分辨率上限、帧率（15–120）、码率上限（0.5–50 Mbps）、编码格式和自适应码率。控制台只提供本机能硬件解码的格式；被控端没有对应的硬件编码器时会自动回退，工具栏上显示实际用的编码器。

**缩放优先**：对方的屏幕比要的分辨率大（例如 4K、Retina 屏缩到 1080p）时怎么缩小。**低延迟**（默认）在对方的显卡上缩放，画面不经过 CPU，延迟和对方的 CPU 占用都低得多；**文字清晰**在对方的 CPU 上用更锐利的算法缩放，缩小很多时细小的文字更清楚，代价是每帧多出十几到几十毫秒、对方的 CPU 占用更高。不需要缩放时两者一样。对方的显卡不支持时自动用 CPU 缩放。

分辨率上限之外，画面也不会超过它在窗口里实际显示的大小：窗口比对方的屏幕小时，被控端直接把画面缩到窗口的大小，控制台按 1:1 显示，不再缩放第二次（文字更清楚，也更省带宽）。拖动窗口边框时，停下来之后才切换分辨率。切换为“原始大小（1:1）”时不受窗口限制。

**画面增强（本机）**：关 / 弱 / 中 / 强，默认关。画面比窗口小、要放大显示时（例如用 1080p 的预设全屏看 2K / 4K 屏），在这台电脑的显卡上用更锐利的算法（Catmull-Rom）放大，再按亮度适度锐化文字边缘；1:1 显示时只锐化。不增加带宽，对延迟几乎没有影响。太强会让压缩的痕迹（块状、文字边上的毛刺）更明显，码率低时选弱。只作用于正在操作的连接（多屏总览的缩略图不处理），对所有连接生效，选择记在这台电脑上。浏览器不支持 WebGL2 时退回浏览器自己的高质量缩放（不锐化）。想要画面真正更清楚，还是要提高分辨率上限和码率：增强只能让收到的画面显示得更好。

**本地光标（本机）**：默认打开。对方是 Windows 时，拖动、缩放窗口期间它会把光标直接画进画面里。打开时照样显示这台电脑的光标，跟手不延迟，只是和画面里那个（稍慢一点）一起有两个；关闭时只看画面里的那个。不管开不开，鼠标都照常按位置操作，不会锁定。对所有连接生效，选择记在这台电脑上。

### 麦克风

把这台电脑的麦克风发给对方：对方电脑上的程序（开会、语音输入、发语音消息）把录音设备选成它的虚拟麦克风，就能听到你说话。默认关闭，每个连接单独打开（工具栏的麦克风按钮 → **把本机麦克风发给对方**），只在正在查看那个连接时发送；第一次打开时浏览器会问能不能用麦克风（桌面版不问）。

- **对方是 Windows**：用的是 Steam 远程同乐的虚拟声卡 **Steam Streaming Microphone**（Valve 的、微软签过名的驱动）。对方电脑上装了 Steam、用过一次 Steam 远程同乐（Remote Play）就有；Nife Remote 不带、也不安装它。没有它时麦克风菜单里会说明
- 在对方电脑的程序里把录音设备选成“麦克风 (Steam Streaming Microphone)”（英文系统是 “Microphone (Steam Streaming Microphone)”），或者在那台电脑的“声音设置 → 输入”里把它设为默认，Windows 的语音输入（Win+H）等用默认麦克风的程序就直接听得到
- 同一时刻只给一个控制端；别的控制端打开时会显示“另一个控制端正在用”，那个关掉之后自动换过来

## 界面语言

控制台和托盘菜单支持**简体中文**和**英文**。默认跟随系统显示语言：系统是中文就用中文，否则用英文。可以在控制台设置（右上角齿轮）里的“中文 / EN”或托盘菜单的“更多 → 语言 / Language”随时切换。选择不保存，下次启动重新跟随系统语言。

对方电脑和服务器发来的提示、错误都是消息类型而不是文字，所以总是按**你自己**的语言显示。日志（客户端和服务端）统一是英文。
